# Me Cash

Step 1 of the Pakistan-based micro-task earning platform: premium marketing landing page, bilingual-ready RTL language toggle, mock live activity feed, and authentication screens.

## Run locally

```bash
npm install
npm run dev
```

Routes: `/`, `/login`, `/signup`, `/forgot-password`, `/dashboard/profile`.

This step intentionally uses mock data only. Supabase/Auth backend and the full dashboard are reserved for Step 2.
